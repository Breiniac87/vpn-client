# 📋 Шаблон и Промпт для настройки Мульти-Агентной системы в любом проекте

Этот файл содержит **готовый универсальный промпт** и **инструкцию**, которые вы можете скопировать и отправить агенту Antigravity в **любом новом или существующем проекте** (на Swift, TypeScript, Python, Go, Rust и т.д.), чтобы моментально развернуть точно такую же ролевую систему с поддержкой **skills.sh** и **subagents.cc**.

---

## 🎯 ГОТОВЫЙ ПРОМПТ (Скопируйте в новый проект)

```markdown
Настрой в этом репозитории мульти-агентную рабочую среду для параллельной работы сессий в Antigravity с интеграцией skills.sh и subagents.cc по следующему плану:

1. **Анализ проекта:**
   - Определи язык, стек, фреймворки и структуру проекта (код, тесты, UI/ассеты, документация).

2. **Загрузка и установка скиллов из skills.sh:**
   - Установи через команду `npx -y skills add <repo> --skill <name> -a antigravity --copy -y` лучшие отраслевые скиллы под стек проекта:
     * Для тестирования: `mattpocock/skills` (скиллы: `tdd`, `diagnosing-bugs`)
     * Для синхронизации между агентами: `mattpocock/skills` (скилл: `handoff`)
     * Для дизайна и UI: `anthropics/skills` (`frontend-design`) или специфичные под платформу (например, `apple-design` для macOS/iOS, `tailwind-design-system` для веба)
     * Для разработки: найди профильные скиллы под стек через `npx -y skills find <стек>`
     * Скачай агента Solution Architect: `mkdir -p .claude/agents && curl -L -o .claude/agents/solution-architect.md https://subagents.cc/api/download/solution-architect` и продублируй его в `.agents/skills/solution-architect/SKILL.md`.

3. **Создание ролевых профилей (`.agents/skills/`):**
   Создай локальные скиллы со строгим разделением зон ответственности:
   - `coder`: разработка бизнес-логики, архитектура, сборка.
   - `tester`: написание тестов, TDD, анализ багов (не меняет код напрямую, пишет падающие тесты).
   - `designer`: UI-компоненты, дизайн-система, генерация графики и ассетов.
   - `solution-architect`: декомпозиция и выбор технологий, ADR, спецификации.

4. **Глобальные правила и предотвращение конфликтов:**
   - Создай в корне `AGENTS.md` с описанием ролей, ключевых слов вызова и правил изоляции файлов.
   - Создай `.agents/rules/multi-agent-roles.md` с правилами работы нескольких сессий на одном репозитории.
```

## 🛠️ Как устроена эта система (Шпаргалка для других проектов)

### 1. Архитектура файлов в проекте
Любой проект с настроенными ролями имеет следующую структуру:

```text
Ваш_Проект/
├── AGENTS.md                                # Корневые правила: агент читает их при старте сессии
├── .agents/
│   ├── rules/
│   │   └── multi-agent-roles.md             # Правила изоляции файлов и предотвращения конфликтов
│   └── skills/                              # Каталог скиллов (распознаётся Antigravity)
│       ├── coder/SKILL.md                   # Профиль разработчика
│       ├── tester/SKILL.md                  # Профиль QA
│       ├── designer/SKILL.md                # Профиль UI/UX дизайнера
│       ├── solution-architect/SKILL.md      # Профиль архитектора
│       ├── tdd/                             # Из skills.sh
│       ├── diagnosing-bugs/                 # Из skills.sh
│       ├── handoff/                         # Из skills.sh
│       └── ...                              # Профильные скиллы стека
└── .claude/agents/                          # Для совместимости с Claude Code / subagents.cc
    └── solution-architect.md
```

### 2. Как работать в параллельных окнах (Workflow)
1. **Запуск:** В боковой панели Antigravity нажимаете **«New Conversation»** для каждого нужного потока.
2. **Ролевой старт:**
   - В Окне 1: `«Ты архитектор. Сделай декомпозицию задачи X и составь спецификацию...»`
   - В Окне 2: `«Ты кодер. Реализуй задачу по спецификации...»`
   - В Окне 3: `«Ты тестировщик. Напиши тесты методом TDD...»`
   - В Окне 4: `«Ты дизайнер. Разработай UI-компоненты и внешний вид...»`
3. **Синхронизация между окнами (Handoff):**
   - Когда один агент закончил этап, напишите ему: `«Сделай handoff для кодера/тестировщика»`.
   - Скопируйте сгенерированный компактный отчет в соседний чат.
