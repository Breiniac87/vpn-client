# 🛡️ X-project — macOS VPN & Proxy Client

**X-project** — современный, быстрый и нативный клиент прокси и VPN для macOS, созданный на базе **SwiftUI** и мощного ядра **Xray-core**.

---

## ✨ Основные возможности

* **Поддержка современных протоколов:**
  * **VLESS** (с поддержкой XTLS Reality, Vision, Flow, WebSocket, gRPC).
  * **Trojan** (TLS, WebSocket, gRPC).
  * **Shadowsocks** (включая современные шифры AEAD).
* **Режимы перехвата трафика:**
  * **System Proxy (Системный прокси):** автоматическая настройка HTTP/HTTPS и SOCKS5 прокси для активных сетевых служб (Wi-Fi, Ethernet).
  * **TUN-режим:** перенаправление системного трафика через виртуальный TUN-интерфейс.
* **Нативный интерфейс macOS:**
  * Удобный виджет в **Menu Bar** (строке меню) с быстрым переключением туннеля одной кнопкой.
  * Интерактивный график задержки (ping/latency) в реальном времени.
  * Стильное окно настроек с тёмно-золотой акцентной темой и вкладками (Серверы, Сеть, Маршрутизация, Журнал).
* **Импорт серверов и конфигураций:**
  * Добавление по ссылкам (`vless://`, `trojan://`, `ss://`) прямо из буфера обмена.
  * Встроенный сканер **QR-кодов прямо с экрана** macOS.
  * Импорт полных JSON-конфигураций.
  * Поддержка **подписок** (V2Ray / Base64 / Clash) с автоматическим обновлением.
* **Гибкая маршрутизация:**
  * Встроенные актуальные базы **GeoIP** и **GeoSite**.
  * Готовые профили маршрутизации: Direct, Bypass Russia / China, Proxy All.
  * Поддержка схем маршрутизации HAPP и кастомных правил.
* **Надёжность и безопасность:**
  * Автоподключение к последнему серверу при старте приложения.
  * Интеллектуальное сохранение и восстановление выбранного сервера при обновлении подписок (даже при смене доменов).
  * Автоматический сброс системных прокси при выходе или аварийном завершении (`cleanupDanglingProxies`), чтобы интернет не пропадал.

## 💻 Системные требования

* **macOS 14.0 (Sonoma)** или новее.
* **Архитектура:** Apple Silicon (M1 / M2 / M3 / M4) или Intel (x86_64).
* **Инструменты разработчика:** Xcode Command Line Tools или полный Xcode:
  ```bash
  xcode-select --install
  ```

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/Breiniac87/vpn-client.git
cd vpn-client
```

### 2. Загрузка ядра Xray-core (если требуется)

В проекте уже присутствуют необходимые файлы ядра в папке `bin/xray/`. Если вы хотите обновить их до последней версии под вашу архитектуру Mac:

```bash
./scripts/download_xray.sh
```

### 3. Сборка `.app` приложения

Запустите скрипт автоматической сборки бандла:

```bash
./scripts/build_app.sh
```

Скрипт выполнит:
1. Компиляцию проекта через Swift Package Manager.
2. Создание полноценного macOS-бандла `build/X-project.app`.
3. Встраивание ядра `xray`, баз `geoip.dat` и `geosite.dat`.
4. Установку иконок приложения и генерацию `Info.plist`.

### 4. Запуск приложения

```bash
open build/X-project.app
```

*Вы также можете переместить `build/X-project.app` в папку `/Applications` («Программы»).*

Вы можете запускать и тестировать проект напрямую через терминал с помощью Swift PM:

## 📖 Руководство пользователя

### Добавление сервера
1. Нажмите на иконку **X-project** в строке меню или откройте окно настроек (`Cmd + ,`).
2. Во вкладке **«Серверы»** нажмите **«+»**:
   * **Из буфера обмена:** скопируйте ссылку `vless://...`, `trojan://...` или `ss://...` и выберите импорт.
   * **Сканировать QR-код с экрана:** приложение определит QR-код, отображаемый на экране Mac (потребуется однократное разрешение на запись экрана).
   * **Импорт JSON файла:** выберите готовый файл конфигурации Xray.

### Управление подписками
1. В настройках перейдите во вкладку подписок.
2. Вставьте URL вашей подписки и нажмите «Добавить».
3. Включите **«Автообновление подписок»**, чтобы приложение поддерживало актуальный список узлов.

### Выбор сервера и подключение
* Нажмите на тумблер включения в строке меню для активации туннеля.
* В списке серверов выберите нужную локацию. Значок задержки (ping) покажет доступность узла.

```
vpn-client/
├── Package.swift                  # Конфигурация Swift Package Manager
├── Sources/XProject/
│   ├── App/                       # Точка входа, AppState, контроллеры окон и MenuBar
│   ├── Core/
│   │   ├── Models/                # Модели данных (ServerProfile, Settings, RoutingRule и др.)

│   │   ├── Subscriptions/         # Менеджер подписок и их обновление
│   │   ├── Testing/               # Встроенный раннер тестов (SelfTestRunner)

│   ├── download_xray.sh           # Загрузка актуального Xray-core под текущую архитектуру
```

## 🔒 Разрешения macOS

При первом использовании macOS может запросить разрешения:
1. **Запись экрана (Screen Recording)** — требуется только при использовании функции *«Сканировать QR-код с экрана»*.
2. **Сетевые настройки** — для переключения системного прокси используются стандартные системные утилиты macOS (`networksetup`).
